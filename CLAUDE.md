## Project Overview
This project provide tools to create workout plans specific to road cycling. The basic
tools are Claude AI working with TrainingPeaks. The latter is accessed via an MCP
server which depends on a current login cookie. As such this access may require a
refresh of that cookie from time to time, so be aware of that.
